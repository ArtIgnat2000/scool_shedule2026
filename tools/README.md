# Инструменты проекта

Скрипты для сборки PDF и проверки сценариев. Не являются частью сайта; в сборку
не входят, на GitHub Pages не публикуются.

## Подготовка окружения (один раз)

```bash
python3 -m venv .venv-pdf
.venv-pdf/bin/pip install reportlab fonttools pymupdf
```

Для DOM-проверки сайта нужен node и jsdom:

```bash
cd tools && npm i jsdom
```

## Сборка PDF из сценария

```bash
.venv-pdf/bin/python tools/md2pdf.py docs/scenario-grade2.md docs/scenario-grade2.pdf "Сценарий открытого урока · 2-й класс"
.venv-pdf/bin/python tools/md2pdf.py docs/scenario-grade4.md docs/scenario-grade4.pdf "Сценарий открытого урока · 4-й класс"
```

Особенности конвертера: A4; таблицы с 5+ колонками (тайминг, раскадровка)
автоматически переносятся на альбомные страницы вместе с заголовком раздела;
шрифты DejaVu (полная кириллица, включая ⟦⟧ и ☐); колонтитул с номером страницы.
Эталон: `docs/scenario-grade2.pdf` в коммите — 104 891 байт, md5
`0479bd40f608f8f678eac4fde2f54121` (пересборка должна давать тот же объём текста;
байт-в-байт совпадение не гарантируется из-за метаданных — сверяйте по страницам/тексту).

## Проверки

| Команда | Что проверяет |
|---|---|
| `node tools/check-times.mjs` | Исполняет настоящий код `index.html` (константы + `generateTimes` + `lessonRow`): совпадение вычисленного времени со всеми записями `schedule.json`; пустая строка среды; сдвиг всех времён при `SCHOOL_START_M = 0` |
| `node tools/check-render.mjs` | Полный рендер сайта в jsdom с реальным `schedule.json`: 37 строк, пустое имя 8-го урока среды, чип «Сегодня», поведение при смене константы |
| `python3 tools/check-docs.py` | Тайминг сценариев: блоки идут без разрывов и в сумме дают ровно 15:00 |
| `python3 tools/check-md.py` | Целостность Markdown-таблиц и объём речи ведущих по блокам (110 слов/мин) |

## Локальный показ сайта без интернета

Данные загружаются через `fetch('schedule.json')` (`index.html:719`), поэтому
простого открытия файла недостаточно:

```bash
python3 -m http.server 8080 --bind 0.0.0.0   # из корня репозитория
```

В песочнице Arena превью доступно как `https://8080-<sandboxId>.e2b.app/`, но
внешние ссылки требуют заголовок `e2b-traffic-access-token`, который браузер по
голой ссылке не отправляет; для раздачи файлов используйте GitHub raw-ссылки.
