## 1. Суть проекта в одном абзаце

Семья с двумя школьниками (год назад: 3-й и 1-й классы) устала контролировать уроки,
кружки и спортивную форму — идея родителей, реализация вместе с Витей, который сейчас
учится в 4-м классе и был настоящим разработчиком: дизайн, код, тестирование, правки по
обратной связи учителя (подтверждённые: начало уроков 8:00 → 8:30; дата начала осенних
каникул). Расписание опубликовано (им пользуются и бабушки/дедушки), есть отдельные копии
для других детей, в т.ч. функционально аналогичная копия для 2-го класса. На этом реальном
примере готовятся два отдельных открытых урока — для 2-го и 4-го классов — о том, для кого,
зачем и как создаются сайты и программы, с переводом идей Вигерса и Битти на детский язык.
Витя — полноценный соведущий; он также обучает детей Scratch в платной онлайн-школе V-labs
с бесплатным пробным уроком, но урок не должен быть её прямой рекламой.

Публичные ссылки: расписание — https://artignat2000.github.io/scool_shedule2026/ ;
V-labs — https://artignat2000.github.io/school/ ;
книга Вигерса и Битти (рус. 3-е изд.) — https://cs.petrsu.ru/~ybgv/Progproject/ucheb/Vigers-treb.pdf .

## 3. Зафиксированные решения (не переоткрывать без пользователя)

- Формат каждого урока: **15:00 законченной обязательной части + один необязательный модуль 3–5 минут**; точки безопасного завершения: 2-й класс — 10:00 и 15:00, 4-й класс — 8:00 и 15:00.
- Два разных урока, не «один материал дважды»: 2-й класс — предметная история, робот-помощник, минимум терминов; 4-й класс — роль разработчика, требования, одна строка данных, сопровождение.
- Витя — соведущий: 5 коротких включений по 20–50 секунд; его реплики в сценариях — **опора**, на карточках 2–3 слова; не называть гением; взрослый берёт сбои на себя.
- Робот-помощник: рабочее имя «Робик», имя и характер выбрать вместе с Витей; не озвучивается голосом; движения только по клику ведущего, стоп-кадр; три смысловых появления (просыпается; вопросы → набросок; хаос → экран) + кадр «8:00 → 8:30» и прощание; не заменяет живого Витю.
- Пустой восьмой урок среды — **скрывать строку полностью**; на уроке использовать как пример «сначала уточнили смысл данных, потом выбрали отображение».
- QR-политика: общий печатный QR — **только на расписание**; QR V-labs **не входит** в презентацию и общую раздатку; отдельная родительская карточка выдаётся Витей после урока только тем, кто сам подошёл.
- Финальные реплики Вити — нейтральные, без призыва купить; сведения о платном формате и пробном уроке — только на родительской карточке (тексты реплик зафиксированы в сценариях).
- Игры для модулей: предварительные кандидаты **«Лифт»** (2-й класс) и **«Geometry Dash»** (4-й класс); слот модульный, замена не ломает сценарий; финальный выбор — до раскадровки демонстрации и офлайн-репетиции; критерии выбора перечислены в плане (раздел 10) и сценариях.
- Рабочий сайт не менять; для показа — учебные копии; три равноправных технических режима; план Б без проектора — плакаты и карточки, ноутбук как реквизит.
- Анимация только смысловая (показывает изменение), без декоративных GIF, мигания, музыки; изображения генерировать единым комплектом **после** утверждения раскадровки; финальную презентацию до этого не делать.

## 4. Проверенные факты о коде (ссылки действительны на коммит `0de7809`)

Проверено исполнением настоящего кода (`tools/check-times.mjs`, `tools/check-render.mjs`):

- `schedule.json`: 5 дней, **37 уроков**; строка = `["номер", "время", "название"]`; вторник, 1-й урок — `schedule.json:13`; среда, 8-й урок с пустым названием — `schedule.json:29`.
- Время **вычисляется** кодом из констант `SCHOOL_START_H/M`, `LESSON_DURATION=40`, `BREAKS=[20,20,10,20,10,10,10]` (`index.html:602–605`, `generateTimes` — `index.html:611–622`); вычисленные значения совпали со всеми 37 записями JSON (0 расхождений).
- «Одно число меняет всё»: при `SCHOOL_START_M = 0` вторник = 8:00–8:40, 9:00–9:40, 10:00–10:40, 10:50–11:30, 11:50–12:30, 12:40–13:20, 13:30–14:10; последний урок понедельника 14:20–15:00. Это реальная механика правки 8:00 → 8:30.
- Значок и название разделяются при рендере (`lessonRow`, `index.html:656–673`): из `["1","8:30–9:10","🧮 Математика"]` — значок 🧮 в плитке, название «Математика» отдельно.
- Среда, 8-й урок сейчас рисуется так: №8, автоматически подставленный значок 📘, время 14:50–15:30, **пустое** название.
- Карточка «Начало уроков в 8:30» — статичный текст разметки (`index.html:542`, `548–549`, `586`) и **не пересчитывается**: в демонстрации со сменой константы на экране будет противоречие — в учебной копии менять и текст карточки либо не показывать её (в сценарии это оформлено как учебный момент «факт записан в двух местах»).
- Техническая фраза `«1-й урок 8:30–9:10 · как на картинке, исправлено с 8:00»` — `index.html:549`; перед показом в учебной копии оставить только «1-й урок 8:30–9:10».
- Карточка-ссылка «V labs — Школа программирования» на самом сайте — `index.html:552–559`: выглядит как реклама; в учебной копии скрыть, в живом показе не задерживаться.
- Нижний dock «Еда / Каникулы / Доп» — `index.html:588–592`; «Каникулы» удобно связать с историей про дату каникул.
- Данные грузятся через `fetch('schedule.json')` (`index.html:719`) → для офлайн-показа нужен локальный сервер (`python3 -m http.server 8080` из корня репозитория); при ошибке страница честно показывает «⚠️ Не удалось загрузить расписание: …» (`index.html:725`).
- Открывается текущий будний день и чип «Сегодня» (`index.html:689`, `704`, `723`); в выходной — нет чипа и открывается понедельник; об этом можно сказать вслух.
- В `index.html` 749 строк; целиком на уроке не открывать.

## 7. Особенности окружения и процесса

- Между turn песочница может сбрасываться: выживает только содержимое репозитория. Новые важные файлы — коммитить в `arena/01a0c808-scool-shedule2026` (push только в неё).
- `.venv-pdf` не сохраняется: пересоздавать (`python3 -m venv .venv-pdf && .venv-pdf/bin/pip install reportlab fonttools pymupdf`).
- `apt-get` без сети; системный `pip` заблокирован PEP 668 — только venv; `npm` работает (jsdom ставится за секунды).
- Кириллические шрифты — только DejaVu (`/usr/share/fonts/truetype/dejavu/`); покрытие всех символов сценариев, включая ⟦⟧ и ☐, проверено (кроме DejaVuSerif: нет ⟦⟧, поэтому в PDF используется Sans).
- Раздача файлов пользователю — через GitHub raw/blob после коммита; ссылки `…e2b.app` снаружи требуют токен-заголовок и для пользователя не работают.
- Проверенные команды — в `tools/README.md`; после правок сценариев прогонять `tools/check-docs.py` (тайминг 15:00) и `tools/check-md.py` (таблицы/объём речи).

## 8. Ограничения пользователя (полный список, кратко)

- Два отдельных урока: 2-й и 4-й классы; по списку ~30, фактически ~20 детей.
- Завершать за 15 минут, максимум 20; заранее подготовленное необязательное расширение.
- Интернет и проектор возможны, но не гарантированы; план Б без интернета обязателен; учитывать отсутствие проектора.
- Расписание — близкий детям реальный пример; источник — семейная проблема год назад (3-й + 1-й класс, спортивная форма); идею предложили докладчик и жена; делали вместе с Витей; опубликовано для родителей/бабушек/дедушек; были индивидуальные расписания для других детей.

- Для 2-го класса есть отдельная функционально аналогичная копия расписания.

- Предварительные игры «Лифт» и «Geometry Dash»; персонаж 2-го класса — робот-помощник; пустой урок скрывать.

- Использовать лучшие практики и книгу Вигерса и Битти (прочитана; выводы и ссылки — в плане).
- Итог этапа — план и сценарии с раскадровкой; финальную презентацию не создавать до утверждения раскадровки.
