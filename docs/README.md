# Документы открытых уроков

Материалы для двух открытых уроков «Как рождается полезный сайт» на примере школьного расписания.

| Файл | Что внутри | Статус |
|---|---|---|
| `handoff.md` | Передача работы в новый чат: контекст, зафиксированные решения, проверенные факты о коде, открытые вопросы, следующие шаги, особенности окружения | Читать первым в новом чате |
| `open-lesson-plan.md` | Общая концепция: аудитория, роли взрослого и Вити, методика, технические режимы, план из девяти этапов, риски и критерии готовности | Согласован по содержанию |
| `scenario-grade2.md` | Точный сценарий урока для 2-го класса: тайминг 15:00, реплики по восьми блокам, раскадровка из девяти кадров, вариант без проектора, правила робота-помощника, два модуля расширения, карточки-опоры | Черновик для репетиции |
| `scenario-grade4.md` | Точный сценарий урока для 4-го класса: тайминг 15:00, реплики по восьми блокам, три технические демонстрации с проверенными фактами о коде, раскадровка из десяти кадров, вариант без проектора, три модуля расширения, карточки-опоры | Черновик для репетиции |

Инструменты сборки и проверок лежат в `../tools/` (конвертер Markdown → PDF,
проверки тайминга 15:00, целостности таблиц и исполнения кода сайта); команды —
в `../tools/README.md`.

## Что ещё не сделано

- финальное оформление презентаций — намеренно отложено до утверждения раскадровки;
- иллюстрации и персонаж робота-помощника — генерируются единым комплектом после утверждения раскадровки;
- рабочий сайт (`index.html`, `schedule.json`) **не изменялся**: технические правки описаны в сценарии как отдельная задача и выполняются в учебных копиях.

## Что нужно утвердить

1. Реплики Вити — он говорит своими словами, поэтому текст нужно сократить до опорных слов вместе с ним.
2. Детали, помеченные **⟦уточнить⟧**, — подтверждаются на семейном интервью.
3. Рабочий адрес и локальная копия расписания 2-го класса — в этом репозитории лежит расписание 4 «Б».
4. Порядок и состав кадров раскадровки.
5. Окончательные игры для модулей расширения: рабочие кандидаты — «Лифт» (2-й класс) и «Geometry Dash» (4-й класс).
